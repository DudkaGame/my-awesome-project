# Revo Coffee Website

## Описание

Верстка одностраничного сайта (лендинга) для магазина кофе.
На странице реализованы:

-   Главный баннер
-   Секция с преимуществами
-   Каталог кофе и подарочных наборов

## Технологии

-   HTML5
